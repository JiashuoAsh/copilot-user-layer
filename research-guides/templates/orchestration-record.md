# 项目科研协作记录模板

仅在实际项目需要时按已有布局填写；删除无关占位，不在用户层写项目事实。

## 目标与所有者

- effort / 当前课题标识与目标：
- 代码库 / worktree / 课题记录目录与实际入口：
- 数据与运行产物位置（按当前动作需要）：
- root 会话 / 最近活动时间：
- 模式来源与范围（Auto 写“Research Auto 默认授权”，不是批准队列；其他模式记录实际范围）：
- 本轮交付、验收和停止条件：
- brief / proposal / method 或 methods 当前项 / evidence / protocol / implementation / 既有协作记录引用（按需）：

## 当前版本与决定

| ID / revision | 内容或产物引用与指纹 | 决策状态 | 证据状态 | 依赖 | 变更原因 |
|---|---|---|---|---|---|

Q/H 指研究问题/假设，M 指方法，P 指实验协议。无预设假设时记录探索目标。版本更新保留历史，不默默覆盖。

## 任务与验收

| task / parent | owner | 交付与验收 | 输入 revisions / 指纹 | blockers | 独占写入 / worktree | authority | status | validity | 证据与审阅 |
|---|---|---|---|---|---|---|---|---|---|

status 为 ready / running / awaiting-review / complete / blocked / failed / cancelled；validity 为 current / stale。没有报告不等于没有执行，重派前检查产物和运行凭据。

## 本轮预算

| round | 总额度 | 分支与预留额度（含 Lead） | 已消耗（含失败重试） | 已返回未用额度 | 继续依据 |
|---|---|---|---|---|---|

默认六次调用，不按每个负责人各给六次。资源、时间与可启动 run 范围单独记录。

## 运行索引

| run | task / protocol revision | code / config 指纹 | 主机 / GPU UUID | 进程或 job 身份 | 状态 / 退出码 | 日志与指标 | 下次检查时间 |
|---|---|---|---|---|---|---|---|

## 跨线问题与版本失效

| 问题 / 观察 | 来源证据 | 接收工作线 | 需区分的解释 | 影响任务/版本 | 处理与结果 |
|---|---|---|---|---|---|

## 下一步与阻塞

记录可独立推进任务、实际等待条件、明确限制或缺失事实及验收未覆盖范围。Auto 自行补齐课题内动作范围与方案，不把未逐项列许可作为阻塞；其他模式仍按实际任务范围。不要生成泛化的人工验证清单。
